# Connectify 🚀
### Real-Time Chat, Video Calling & Media Sharing Platform

Connectify is a full-stack real-time communication platform built with the **MERN Stack** and powered by **Socket.IO** and **WebRTC**. It enables instant messaging, 1:1 HD video calling, and secure media sharing with fast, reliable performance.

## ✨ Features

- 💬 **Real-time messaging** using Socket.IO with instant synchronization across devices
- 📹 **Low-latency 1:1 video calling** powered by WebRTC
- 📁 **Media sharing** for images, videos, and large files
- ⚡ **Optimized file uploads** with efficient buffer handling and cloud storage integration
- 🔐 **Secure authentication** using JWT and HTTP-only cookies
- 📱 **Responsive design** for smooth experience across all devices
